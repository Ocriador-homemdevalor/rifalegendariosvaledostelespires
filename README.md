# Legendários Vale do Teles Pires

Site HTML de participação gratuita em 100 números, com solicitação, confirmação manual e descrição editável pelo organizador.

Hospedagem: GitHub Pages. Login e banco: Firebase Authentication com Google e Cloud Firestore no plano gratuito Spark.

Publique os arquivos desta pasta na raiz do repositório. Depois abra a Área ADM com a conta autorizada, preencha o prêmio, a descrição e as regras e abra as inscrições. O domínio do GitHub Pages deve estar autorizado no Firebase Authentication.

Os contatos não ficam no repositório nem na consulta pública de números. As permissões são aplicadas pelas regras do Firestore; ocultar o painel no navegador não é a proteção de acesso.

Um número por conta Google. O ADM pode confirmar, recusar e liberar pedidos ou registrar manualmente uma participação gratuita. A disponibilidade é compartilhada pelo banco, com reservas atômicas. Alterar o prêmio e a descrição não exige reenviar o HTML.

Fotos JPG, PNG e WebP de até 450 KB, ou URL HTTPS. A cota gratuita tem limites; o projeto deve permanecer no plano Spark para não habilitar faturamento por uso.

Não publique backups de participantes, comprovantes, senhas ou chaves de serviço neste repositório.
